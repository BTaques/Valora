# Valora — Login original + Dashboard

O Login e o modal de cadastro são os arquivos originais do ZIP `tela 1 com modal(1).zip`. O Dashboard utiliza o JSX e os assets exportados do Figma pelo Locofy, com correção do contêiner principal para manter a composição desktop.

## Executar

```bash
npm install
npm start
```

Acesse a rota `/` para Login e clique em Entrar para abrir `/dashboard`.

A tela de Dashboard foi concebida para 1440×1024 e pode exigir rolagem horizontal em janelas menores.
